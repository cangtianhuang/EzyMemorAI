# EzyMemorAI —— 您的智能文件助手AI 🚀

在信息爆炸的时代，管理文件、快速检索知识和高效处理任务变得愈发重要。**EzyMemorAI** 应运而生，成为您贴心的智能助手，帮助您轻松应对文件管理、知识检索和智能对话的挑战。无论是整理杂乱的文件、实时监控文件夹变化，还是通过智能聊天快速获取信息，EzyMemorAI 都能为您提供高效、便捷的解决方案。更重要的是，EzyMemorAI 支持**本地部署**和**API 轻量部署**，确保您的数据安全与隐私，同时保持轻量化运行，随时随地为您服务。

---

## ✨ 核心功能

### 1. **智能文件整理**
   - **文件树预览**：生成清晰的文件树结构，让您的文件系统一目了然。
   - **AI自动整理**：根据文件类型、内容或自定义规则，AI 将自动整理您的文件。
   - **递归整理**：支持递归整理文件夹，彻底解决文件混乱问题。
   - **选择性执行**：直观对比整理前后的文件树，您可以反复生成到满意后执行。

### 2. **智能聊天与知识检索**
   - **RAG 技术**：基于 Retrieval-Augmented Generation 技术，快速从您的文档库中检索信息。
   - **AI精准回答**：提供含有引用来源的准确、可靠的答案，杜绝 AI 幻觉。
   - **流式聊天**：支持流式对话，让对话更加自然流畅。
   - **多轮对话**：支持上下文记忆，实现多轮对话的无缝衔接。（开发中）

### 3. **文件夹实时监听**
   - **实时监控**：自动监控指定文件夹的变化，及时处理新增文件。
   - **动态更新**：任何文件变化将更新至文档数据库，实时反应在智能聊天中，确保您的知识库永不过时。
   - **灵活控制**：随时启动或停止监听，完全掌控您的文件管理流程。
   - **自动整理**：新增文件自动分类并整理到指定位置，确保文档库始终最新。（开发中）

### 4. **文档数据库管理**
   - **智能分析**：自动分析文件内容，生成摘要或关键词，助您快速掌握核心信息。
   - **可视化查看**：随时查看文档数据库内容，了解您的知识库状态。（开发中）
   - **高效管理**：支持文档内容级别的增删改查（而非单个文件），轻松管理您的知识资源。（开发中）

---

## 🛠️ 技术亮点

- **AI 驱动**：结合 RAG 技术和自然语言处理，提供智能化服务。
- **本地部署**：支持大模型完全本地化运行，确保您的数据安全与隐私，无需依赖外部服务。
- **API 轻量部署**：支持通过 API 调用外部大模型服务，轻量化部署，灵活适配不同场景。
- **模块化设计**：功能模块化，便于扩展和维护，满足个性化需求。
- **异步支持**：基于 `asyncio` 实现高效异步操作，提升系统性能。
- **用户友好**：简洁直观的命令行交互，操作简单易上手。
